# Stage 4 — Design

**Goal:** original, print-ready artwork that passes QC by eye before
it ever touches a product.

## The non-negotiable rule

**Original artwork only.** Every design starts from the Stage 3 brief
(your words, your concept) — never from another seller's design, a
franchise, or a brand. If a design needs someone else's IP to work,
the design doesn't work. Kill it and write another.

## File rules (per product — confirm against YOUR provider's specs)

Printify providers publish exact specs per blueprint; the numbers
below are the standard working defaults for apparel DTG
(direct-to-garment). The provider's spec sheet wins any disagreement.

| Rule | Standard |
|---|---|
| Format | **PNG with transparent background** |
| Resolution | **300 DPI** at final print size |
| Typical tee print area | **12" × 16"** (3600 × 4800 px at 300 DPI) |
| Colour mode | sRGB |
| Text | Outlined/converted to paths, or a font licensed for commercial use |
| Margins | Keep critical elements ≥ 0.5" inside the print area edge |

- Design at the largest size you'll sell; scaling down is safe,
  scaling up is blur.
- Thin lines and tiny text die on fabric — minimum stroke and type
  sizes that survive a real print: bold or nothing.
- Check the design on **every garment colour** it will be offered on.
  A design that only works on white is a white-only listing — say so,
  don't ship it on black and eat the returns.

## Typography rules

- One idea per design. If the phrase needs a paragraph, it's a blog
  post, not a shirt.
- Hierarchy: the hook word biggest; supporting text clearly secondary.
- Two fonts max, and they must be a deliberate pairing (display +
  simple sans is the safe classic).
- Letter-spacing and arc effects are seasoning — the phrase must read
  at arm's length, instantly, on a moving person.
- Spell-check out loud. A typo printed 40 times is 40 refunds.
  (This has ended more POD shops' weeks than any algorithm.)

## AI generation rules

- Generate from the brief's concept; use generation for **original
  illustration and lettering exploration**, then finish/clean the
  artwork yourself or with tools — raw generator output often carries
  artifacts, garbled text, and accidental resemblances to training
  data's famous characters. All three are QC failures.
- **Never** prompt with a brand, franchise, artist, or living
  designer's name ("in the style of…"), and never feed another
  seller's design as an input image.
- Keep the generation prompt + date with the design file. If anyone
  ever asks "where did this come from", you have the receipt.

## Design QC checklist — view EVERY design before it ships

- [ ] Viewed at 100% zoom: no artifacts, no stray pixels, no garbled
      letterforms
- [ ] Viewed as a thumbnail (listing size): still readable, still
      punchy
- [ ] Viewed on light AND dark garment mockups
- [ ] Spelling read out loud, twice
- [ ] Transparency clean: no accidental background boxes or halos
- [ ] File is PNG, 300 DPI, sized to the provider's print area
- [ ] IP checklist (Stage 3) re-run against the finished artwork —
      including "does this accidentally look like a known character?"
- [ ] Prompt/source note filed with the design

A design that fails any line gets fixed or killed. There is no
"ship it and see" — a bad print is a refund, a 1-star review, and a
strike against the shop's search standing, all for one listing.

## Stage checklist

- [ ] Design built from the brief, original artwork only
- [ ] File meets provider specs (PNG, transparent, 300 DPI)
- [ ] Typography rules followed; fonts commercially licensed
- [ ] QC checklist passed, by eye, at full size and thumbnail size
- [ ] Source/prompt note filed with the design file

## Shop-type note

The rules above are the apparel path (300 DPI transparent PNG for a
print area). For the other presets the same doctrine — original
work, licensed inputs, QC by eye — takes a different form
(`docs/shop-types.md`): **digital downloads** are designed as files
(SVG/PNG/DXF exported clean, packed in a ZIP, ≤20 MB per file);
**STL files** are modelled (Blender is the reference tool) and
**test-printed by you** before they can be listed — the test print
is this stage's QC for that shop type; **digital templates** are
built as documents and **buyer-tested** (open the delivery PDF,
follow the Canva link in a fresh account, edit, export — that test
is the QC); **coloring books** are produced page by page and
**print-tested** (5+ pages on a home printer; broken lines and
stray AI artefacts are cleaned by a human on every page); and
**pet accessories** reuse the apparel rules plus a personalisation
test — order one of your own items with a test name before the
listing opens, because a misspelt pet name is the category's
signature 1-star review.
